2

Download the Code

  1. Go to github.com/nikkiDong/EVA
  2. Click the green Code button
  3. Click Download ZIP
  4. Unzip the file — this is your entire website
3

Build the Site

  1. Install Node.js from nodejs.org (LTS version)
  2. Open Terminal (Mac) or Command Prompt (Windows)
  3. Navigate to the project folder, then run:
npm install
npm run build
Result: This creates a dist folder — that's what you'll deploy.
4

Deploy to Netlify

  1. Go to netlify.com and create a free account
  2. On the dashboard, find the drag-and-drop area
  3. Drag your dist folder onto it
  4. Wait a few seconds — your site is live at a temporary URL!
Why Netlify? React is the tool that builds the site. Netlify is what hosts it online. It's free, secure, and requires no server setup.
5

Connect Your Domain

  1. In Netlify: Site settings → Domain management → Add EVASmartSystems.com
  2. Netlify will show you DNS records to copy
  3. In your registrar: Go to Advanced DNS → Add the records Netlify provided
  4. Save and wait a few minutes for it to take effect
6

Enable HTTPS

  1. In Netlify: Domain management → HTTPS
  2. Click Provision certificate
  3. Done — your site now has the secure lock icon
✓

Verify

  1. Visit EVASmartSystems.com — homepage should load
  2. Click through all pages (Home, About, Coaching, etc.)
  3. Test on your phone — the site is fully responsive
  4. Check that the lock icon appears in the address bar
